Three heuristic "competent shell user" agents — novice (knows only the obvious encodings), journeyman (adds compression, archives, configs, logs) and expert (adds databases, certificates, filesystem metadata, reversible text transforms) — race in one shared container to claim eight flags, each hidden behind a different Unix feature. Claims are exclusive: a slower agent that recovers the same flag a tick later is sniped. These tiers stand in for the paper's base → GRPO → GRPO+SFT models; a real policy drops into the same policy(observation) → command slot. Every command shown actually ran in a live shell.
